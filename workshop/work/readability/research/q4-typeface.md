# READ-1 · Q4 — Typeface evidence memo

## Finding

**Controlled study:** typeface features can affect legibility, but evidence does not identify a universally superior reading serif. In a vision-science review, larger x-height fractions are associated with more pixels devoted to lowercase forms at a fixed nominal size; the authors discuss this as a plausible legibility advantage, while also emphasizing that print size, acuity and reading task matter. A controlled comparison of Times New Roman and Helvetica found no significant difference in reading speed or errors in paperback reading after matching x-height, spacing and line width. A separate low-vision study found stroke contrast interacted with serif presence in letter identification; it tested a limited set of typefaces and participants with central vision loss, so it cannot rank ordinary text faces for this site. ([Legge & Bigelow, 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3428264/); [Tyrrell et al., 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9804255/); [Beier & Oderkerk, 2023](https://doi.org/10.1016/j.actpsy.2022.103810))

**Expert convention / font documentation:** optical-size designs commonly adjust details such as stroke treatment and spacing for different sizes; the `opsz` axis is a font-design axis, not a claim that the font is more readable in every setting. CSS `font-optical-sizing: auto` requests optical sizing when the selected font supports it. Source Serif 4 officially ships variable `opsz` (8–60) and `wght` (200–900), with Latin and Latin Extended subsets. Literata 3 documents four optical-size series and rebuilt accent anchors/combining diacritics. Newsreader’s project describes it as intended for continuous on-screen reading, says it ships as a variable font, and documents Latin Plus coverage for Western European languages. These are verified project/metadata claims, not comparative reading trials. ([CSS Fonts / MDN reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-optical-sizing); [Source Serif 4 metadata](https://github.com/google/fonts/blob/main/ofl/sourceserif4/METADATA.pb); [Literata 3 notes](https://github.com/googlefonts/literata/blob/main/Documentation/WhatsNew-in-v3.md); [Newsreader project](https://github.com/productiontype/Newsreader))

**Opinion:** Source Serif 4 and Newsreader merit inclusion in a specimen; Literata is also a plausible candidate. Their openly documented Latin/Western European support makes them credible Portuguese candidates, but specimen glyph coverage should be checked in the actual served font files for `á à â ã é ê í ó ô õ ú ü ç` and uppercase forms. This memo does not establish which face performs or feels best for CUFRGS readers. Charter should only enter the comparison after the specific free build and its character coverage are identified; “Charter” names multiple distributions and this evidence set does not verify a particular one.

## Evidence and quality

- **Controlled study / review:** Legge and Bigelow review evidence on print size and vision science. They report that Georgia outperformed Arial and Times New Roman in word recognition in cited work, and explain the x-height/pixel-resolution mechanism; those comparisons do not isolate x-height as the only design variable. The same article stresses fluent-reading performance depends on visual acuity and print size. ([source](https://pmc.ncbi.nlm.nih.gov/articles/PMC3428264/))
- **Controlled study:** Tyrrell et al. equalized x-height, spacing and text width for Times New Roman versus Helvetica and found no significant reading-speed or error difference in paperback format, limiting a simple serif/sans conclusion. ([source](https://pmc.ncbi.nlm.nih.gov/articles/PMC9804255/))
- **Controlled study, special population/task:** Beier and Oderkerk examined serif presence and stroke contrast in low-vision reading/letter identification. Their reported interaction cautions against treating “low contrast” or “serif” as a standalone rule; the study does not test these named web fonts or typical readers. ([source](https://doi.org/10.1016/j.actpsy.2022.103810))
- **Expert convention and official project documentation:** the optical-size behavior and font axes/coverage above come from CSS and font project documentation, not reader outcome data. ([CSS reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-optical-sizing); [Source Serif 4](https://github.com/google/fonts/blob/main/ofl/sourceserif4/METADATA.pb); [Literata](https://github.com/googlefonts/literata/blob/main/Documentation/WhatsNew-in-v3.md); [Newsreader](https://github.com/productiontype/Newsreader))

## Limits

No located head-to-head controlled study compares Source Serif 4, Literata, Newsreader and a named Charter build for sustained Portuguese reading, at the site’s 19 px size and line length. The evidence supports testing clear text faces, not declaring a winner. “Higher x-height” also changes apparent size and page color at the same CSS size, so visual comparison should keep the CSS size and passage fixed and let readers judge both comfort and preference. Free-font repository metadata establishes declared subsets and axes; it does not by itself prove that every deployment’s downloaded subset contains each requested Portuguese glyph.

## CSS implication

For the later switchable specimen, keep passage, 19 px size, measure, line-height, colors and weight constant while changing only the family. Test Source Serif 4 and Newsreader alongside the current face; include Literata if the team wants a third free option. Load the full Latin Extended subset and inspect Portuguese acute, grave, circumflex, tilde, cedilla and diaeresis glyphs in the actual loaded file. Where supported, set `font-optical-sizing: auto`; for Source Serif 4 the documented `opsz` range includes typical reading sizes, but the browser’s automatic value should be checked in computed styles. Keep weight fixed for this reading comparison; MOT-1’s hover-weight test is a separate specimen variable.
